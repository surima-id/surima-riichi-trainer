# Source art

`surima-emblem.png` is the SURIMA emblem, taken from the club site
(`https://surima.id/assets/logo/surima-emblem.png`). It is not shipped —
`public/favicon.ico` and `public/apple-touch-icon.png` are generated from it:
the script ring is cropped away (it turns to mush below 32px), and what is left
is centred on a rounded felt plate so the mark holds its shape on a light or a
dark tab strip.
